# MSCS532 Assignment 5 - Quicksort Algorithm

This repository contains my implementation of the deterministic and randomized versions of the Quicksort algorithm for MSCS532 (Data Structures and Algorithms).

The assignment required:
- Python implementation of deterministic and randomized Quicksort
- A written report explaining the implementation, time and space complexity, and empirical analysis
- A README file with instructions on how to run the code and a summary of findings one should receive.

## Files

- **sort.py**
  - Implements:
    - Deterministic Quicksort (last-element pivot)
    - Randomized Quicksort (random pivot)
  - Includes:
    - Small tests to verify correctness
    - An empirical comparison of deterministic vs randomized Quicksort on arrays of sizes 100 and 500 with random, sorted, and reverse-sorted input
    
- **Assignment 5 Quicksort Algorithm Implementation, Analysis, and Randomization.pdf**
  - APA-formatted report describing:
    - The Quicksort implementations
    - Time and space complexity analysis
    - The impact of randomization
    - Empirical results and interpretation

- **README.md**
  - Instructions and summary (this file)
